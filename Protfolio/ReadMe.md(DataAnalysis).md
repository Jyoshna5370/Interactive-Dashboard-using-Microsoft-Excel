# \# Ashok Store Sales Analysis Dashboard

## 

## \## Project Overview

This project focuses on analyzing Ashok Store sales data using Microsoft Excel. An interactive dashboard was created to understand sales performance, customer purchasing behaviour and business trends.



## \## Objectives

\- Analyze monthly sales and orders.

\- Compare male and female customers.

\- Analyze order status.

\- Identify top 10 states by sales.

\- Understand age group and gender relationships.

\- Identify the highest-performing sales channel.

\- Find the best-selling product categories.

## 

## \## Tools Used

\- Microsoft Excel

\- Pivot Tables

\- Pivot Charts

\- Slicers

\- Excel Formulas

### 

### \## Data Cleaning

\- Checked and corrected inconsistent text labels.

\- Created age groups using IFS formulas.

\- Organized data for analysis.



#### \## Dashboard Features

\- Monthly Sales vs Orders

\- Men vs Women Analysis

\- Order Status

\- Top 10 States

\- Age vs Gender

\- Sales by Channel

\- Sales by Category

\- Interactive Slicers



#### \## Key Insights

\- Women contributed more sales than men.

\- March recorded the highest monthly sales.

\- Amazon was the highest-performing sales channel.

\- Set was the highest-selling category.

\- Maharashtra was the top sales-contributing state.



##### \## Conclusion

The Excel dashboard provides an interactive view of sales performance and helps identify important business trends and customer purchasing patterns.
