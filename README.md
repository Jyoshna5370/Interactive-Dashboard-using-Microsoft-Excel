# Ashok Store Sales Analysis and Interactive Dashboard

## Project Overview
This project analyzes Ashok Store sales data using Microsoft Excel. An interactive dashboard was developed to understand sales performance, customer behaviour, and business trends.

## Project Objectives
- Analyze monthly sales performance.
- Compare male and female customer sales.
- Understand order status distribution.
- Identify top-performing states.
- Analyze age groups and gender.
- Identify the best-performing sales channels.
- Analyze product category performance.

## Tools and Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Formulas

## Data Cleaning
- Checked and corrected inconsistent data entries.
- Created age groups using IFS formulas.
- Organized data for analysis.

## Dashboard Features
- Monthly Sales Analysis
- Gender Analysis
- Order Status Analysis
- Top 10 States by Sales
- Age Group vs Gender Analysis
- Sales by Channel
- Sales by Category
- Interactive Slicers

## Key Insights
- Women contributed more sales than men.
- March recorded the highest monthly sales.
- Amazon was the top-performing sales channel.
- Set was the highest-selling product category.
- Maharashtra contributed the highest state-wise sales.

## Conclusion
This project provides an interactive view of retail sales performance and helps identify important business trends and customer purchasing patterns.
